# v0.10.0 真机验收清单（闸门⑤）

> 用途：红米 AX6 真机验收「对着勾」清单，对应 docs/design.md §3.7 验收标准与铁律 10 观察项。

> 每项通过打勾；失败项记录现象与日志，交程序员处置。

- [ ] 开发机：`./scripts/deploy-prepare.sh` 成功，记录 UPX 后体积：________ 字节
- [ ] 路由器：记录安装目录空闲空间（`df -h`）：________

## 1. 部署与启动

- [ ] 路由器执行 `sh deploy-router.sh`，输出「部署成功」（健康检查 = 进程存活 + 日志出现「Gateway 启动」行，不依赖 wget——AX6 BusyBox wget 无 -S 参数，实测确认）
- [ ] 服务日志落文件：`grep v0.10.0 $INSTALL_DIR/mini-cloud.log` 能看到启动版本号
- [ ] **断开 SSH 会话后服务仍在运行**（脱离会话启动验证，I9）

## 2. 管理页功能（本版本核心，对应 §3.7 验收 2/4/6/7/8）

- [ ] 浏览器打开 `http://<router-ip>:8088/`，根导航页出现「管理」链接
- [ ] 打开 `/admin`：能看到移动云盘挂载与当前健康状态；未登录访问返回 401
- [ ] 输入**错误格式**的 authorization → 提示格式错误，挂载运行不受影响（零变化）
- [ ] 输入**已过期或剩余不足 24 小时**的 authorization → 拒绝接收并提示
- [ ] 输入**正确**的新 authorization → 显示「更新成功，新凭证有效期至 …」
- [ ] 更新后挂载**立即**恢复：目录可浏览、文件可播放（无需等 30 秒）
- [ ] 更新后根导航页显示名恢复正常（过期提示消失）
- [ ] **重启服务后**挂载仍正常（新凭证已持久化到 config.json）
- [ ] 路由器 `ls -l` 核对：config.json、config.json.bak、state/* 均为 0600
- [ ] config.json 中无空 `"cloud": {}` 块
- [ ] 可选（I3 断电可持久）：更新成功后直接断电重启，凭证仍是新值
