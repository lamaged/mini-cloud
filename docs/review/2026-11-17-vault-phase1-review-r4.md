## 1. 处置复核

| 编号 | 意见 | 结论 | 证据 |
|---|---|---|---|
| I8 | 默认配置被写入 `.bak`，自愈可能回退 admin/admin | **关闭** | ①「创建默认配置」分支删除 `ensureBackup`；② 自愈前 `isDefaultBackup(bakCfg)`（admin/admin + 单个 local）→ `slog.Error` + 拒绝恢复 + 原文件不动；③ `TestLoadDefaultConfigNoBackup`（嵌套路径首启无 `.bak`）、`TestLoadSelfHealRefusesDefaultBackup`（默认备份拒自愈、原文件不被覆盖） |
| I9 | README 百度措辞与 P11 行为不符 | **关闭** | 改为「不启用任何 Vault 行为；加密目录按普通目录显示，`_mc` 密文对象可被直接下载（无密钥无法解密）」，副作用明示，与 `process.md 铁律 2` 一致 |
| P14 | 跳过分支无测试 | **关闭** | `fakeRaw.streamOnly` + `onlyReader`（仅 `Read`），`Link` 返回 `io.NopCloser` → 触发跳过；`TestVaultStreamOnlyDriverSkipped` 断言物理视图（含 `_mc`）、零告警 |
| P15 | `.bak` 损坏时永不刷新 | **关闭** | `ensureBackup`：`.bak` 缺失**或** `LoadStrict(.bak)` 失败 → 用当前好配置覆盖；`TestEnsureBackupRefreshesCorrupt` |
| P16 | `.bak` 陈旧度 | **关闭（方案②）** | 明确「仅在缺失/损坏时刷新，保护管理页写前备份的回滚链」；`design §4.3` 写明策略，自愈日志含 `bak_mtime` |
| P17 | `pruneBroken` 排序前提 | **关闭** | 注释写明「10 位秒级时间戳 → 字典序 = 时间序；若改毫秒/纳秒或非定长需改用 mtime 排序」 |
| P18 | `design §4.3` 缺第三态 | **关闭** | 补「驱动能力不足（如百度代理流）→ 完全不建 vault 根，挂载按普通模式，密文目录物理可见」 |

**结论：7 条全部闭环；I8 的修复同时满足"可自愈"与"不会被降级成弱口令"两个目标，取舍正确。**

## 2. 建议

| 编号 | 内容 | 建议 |
|---|---|---|
| P19 | 已存在的"默认 `.bak`"不会被清掉 | 从 `77c1e7e` 升级上来的机器（首启曾写入默认 `.bak`）此后 `ensureBackup` 见 `.bak` 可解析即不再刷新，自愈被永久拒绝，直到用户用过 `/admin`。建议：`ensureBackup` 中若「现有 `.bak` 是默认配置」而「当前配置不是默认」，则顺带刷新一次（一行判断，可与 I8 防线互补） |
| P20 | `isDefaultBackup` 语义偏宽 | 仅以「admin/admin + 单个 local」判定。若用户**真的**只用 local（开发/测试机），自愈会一直被拒。建议改为与 `DefaultConfig()` 做字段级比较（含 `vault == nil`、无额外字段），或在文档/日志中注明该限制 |
| P21 | 拒绝自愈时返回的错误不带原因 | `return nil, err` 返回的是原始 JSON 语法错误，`main` 打印「加载配置失败: unexpected…」；拒绝原因只在 `slog.Error` 里。建议 `fmt.Errorf("备份为默认配置，拒绝自愈：%w", err)`，让 stderr 与日志一致 |

## 3. 回归核对

| 项 | 结论 |
|---|---|
| 首启无 `.bak` | 不再写入；用户首次配置后成功加载才会生成 `.bak`（`ensureBackup` 在成功路径）✓ |
| `.bak` 与自愈的关系 | `.bak` 可解析且非默认 → 可自愈；不可解析 → 先刷新（P15）再按需自愈；为默认 → 拒绝（I8）✓ 三态闭合 |
| 管理页回滚链 | `PersistFunc` 的写前备份与 `RestoreBackup` 未受影响；`ensureBackup` 不主动覆盖有效 `.bak`（P16 方案②）✓ |
| 百度路径 | `streamOnly` 驱动不建根 → `List/Link` 全委托 `cached`；README/design/process 三处表述一致 ✓ |
| 测试覆盖 | 本轮新增 4 组（默认不备份、默认备份拒自愈、`.bak` 损坏刷新、不可 seek 驱跳过）✓ |
